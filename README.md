# 🚚 Landloop System — Smart Logistics Ride Matching

An intelligent logistics platform that reduces empty vehicle miles through real-time load matching and route optimization.

---

## 📌 Project Overview

Landloop System improves logistics efficiency by matching available vehicles with suitable loads using geolocation data and intelligent scoring algorithms.

### Key Benefits
- Higher vehicle utilization  
- Reduced empty return trips  
- Lower fuel and operational costs  
- Reduced carbon emissions  

---

## 🛠️ Tech Stack

- **Vite** — Frontend build tool  
- **TypeScript** — Type-safe JavaScript  
- **React** — UI development  
- **shadcn/ui** — UI components  
- **Tailwind CSS** — Styling
